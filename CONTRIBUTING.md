# Contributing

Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) before changing a product
boundary. Install development dependencies with:

```sh
python3 -m pip install -e '.[test]'
```

## Core experiment changes

Edit `src/phyphox/*.phyphox.xml` and fragments under
`src/phyphox/includes/`. Do not hand-edit matching root artifacts.

```sh
make build
make check-generated
make validate
git diff -- src/phyphox experiments
```

The parity check must pass after the generated diff has been reviewed.

## Astronomy changes

Files in `experiments/astronomy/` are hand maintained and never generated by
the Arduino pipeline. Each file must retain English root content and German and
French translations. Preserve its actual phone, SensorTag, HID, or Owon input
path; do not route it through `phyphox-sense`.

`owon_digital_multimeter-debug.phyphox` is an intentional integration helper.
Its name does not make it disposable build output.

```sh
python3 -m pytest tests/test_astronomy_contracts.py
make validate
```

## Firmware or protocol changes

`protocol/contract.json` owns shared device, UUID, frame, timing, mode, channel,
and filename facts. Update every concrete firmware/XML/preview implementation
that a contract change affects.

```sh
python3 -m pytest tests/test_protocol_contract.py
make validate
make check-generated
make compile
```

The compile target does not upload or test hardware. Report BLE, sensor,
electrical, and phyphox-app verification separately.

## Tooling and CI changes

Keep Make as the contributor-facing interface. `src/curious_signals/` is an
internal implementation boundary. CI and validation must not rewrite tracked
artifacts.

```sh
make lint
make test
make validate
make check-generated
make security
```

Run `make ci` when the network-backed pinned Arduino compile is available.

## Pull requests

Include:

- the behavior or contract changed;
- source and generated files affected;
- commands run and exact outcomes;
- hardware or mobile-app checks performed or skipped;
- compatibility impact;
- remaining release or provenance uncertainty.

Do not include generated archives, local environments, caches, analysis state,
or credentials.
