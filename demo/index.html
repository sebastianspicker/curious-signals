    How it works

    From board to phone in three steps

    1. 01 · Board

      Flash the sketch once

      Use the original Arduino Nano 33 BLE Sense. The Rev2 board has different sensors and won’t work. Upload the sketch from the Arduino IDE; make compile checks that it builds.

      arduino/phyphox_ble_sense/phyphox_ble_sense.ino
    2. 02 · Air

      It advertises itself

      The board appears as phyphox-sense and sends one 20-byte frame at most every 50 ms. Keep one powered board in range: every board uses the same name.

      phyphox-sense · 20 bytes · ≥ 50 ms
    3. 03 · Phone

      Open the file in phyphox

      Copy the experiment file for your mode to the phone or tablet, open it in phyphox, and press play. The app selects the mode for you.

      For mode 5: temperature_plot_v1-2.phyphox

    What this page is, and what it isn’t

    Taken from the repository

    • Device name phyphox-sense
    • Five little-endian float32 values per frame, device time first
    • Channels, units, and wire conversions for modes 1–6 and 9
    • The seven experiment file names

    Simulated here

    • Every trace value: a fixed fixture, identical on every visit
    • No Bluetooth, sensors, network, or storage used by this page
    • Not a measurement, calibration, or proof that a board works

    Check before class

    • One powered board within range at a time
    • Original Nano 33 BLE Sense, not Rev2
    • Pair and run one experiment in the room you teach in
