# Documentation Archive

Historical repository docs live here after they have been superseded, completed,
or deprecated. These files are retained for traceability and are not current
operator guidance.

## Archived Sets

- `2026-05-16-remediation-docs/`: refactor plan, remediation ledger,
  remediation status, code index, verification baseline, architecture map, and
  audit documents from the 2026-05-16 remediation pass.
- `2026-05-16-deprecated-audit/audit/`: older deprecated astronomy audit
  workspace that previously lived under `docs/deprecated/audit/`.
- `2026-06-07-ci-compatibility-docs/`: superseded `docs/ci/` compatibility
  pointers and CI decision note. The active CI overview is `docs/ci.md`.
- `2026-06-07-codacy-local-ledger/`: local Codacy remediation ledger,
  configuration summary, and status evidence from the June 2026 local-only
  remediation pass.

Use the live docs in the repository root and `docs/` for current workflows.
